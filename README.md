## 📖 Overview

GarryBot is a two-wheeled self-balancing robot developed from scratch to gain a practical understanding of embedded systems, robotics, and control theory.

Instead of relying on existing balancing libraries, each subsystem—including the IMU driver, complementary filter, PID controller, and motor driver—was implemented and tested independently. The project emphasizes understanding the engineering principles behind every component rather than simply making the robot balance.

---

## 🎯 Objectives

- Build a self-balancing robot from scratch.
- Learn embedded C++ using PlatformIO.
- Understand IMU sensor fusion.
- Implement a PID controller.
- Develop modular and maintainable software.
- Build a portfolio-quality robotics project.
